# 教程音视频独立审核

**这是单独派发的审核任务。** tutorial-voice-pipeline 与 tutorial-video-pipeline 只负责生成，不自动调用本 skill，不以本 skill 的结果作为下一页生成门禁。当前早期阶段先由用户人工检查；只有用户明确启用机器审核后才开始，不启动后台抽检计划。

## 范围与成本

- 按用户指定的图／页、审核维度和抽样范围执行；未要求全量时不扩成逐页／逐手审核。若用户以后要求采用抽检流程，可选择代表页、复杂变化及普通页样本；每10页抽1页只是一种可选方案，不自动生效。
- 确定性项目先用脚本：实际文件／哈希、解码、时长／尺寸／帧率、音频信号、同源音轨、真实 WordBoundary、对象覆盖及时间线。复用已有结果，模型只接收简明摘要；尚无实现或证据的检查如实记为未检查。
- 用户要求 Astra Max 时，单独派发独立 `gpt-6-astra`／`max`。仅提供必要原图、讲稿／对象／时间线表和两档实际成片代表画面，通常不超过8张截图；复杂变化按具体问题补关键前后帧。不附全部逐手PNG、完整历史日志或整本书上下文。
- 内容重点是来源棋理、颜色／编号、条件与否定、劫／禁例及提子；视觉重点是开场显隐、首次语音结束后出现、软落子、字幕和两档可读性。实际音频／实体设备未体验时不得声称已听／已上机。
- 有可靠编号时不能以 replay 待校准接受全程静态；带标注棋子和独立标记应在明确语音后显现。只看 proof 或 MP4 存在不能替代实际画面审核。

## 结果与停止条件

- 分别记录生成状态、脚本检查结果、模型审核范围／结论、人工审核状态；未抽查页不冒充模型通过，机器结论不写人工审核字段。
- 复用依赖完全一致的有效结论；拒绝后保留原因，只在真实修复后复核受影响部分。抽查失败只扩大到相关问题范围，不自动全书重审，不对同样材料反复请求直到通过。
- 本任务不默认重新生成媒体、改讲稿、改数据库或部署服务；需要修复时按用户授权另行处理。
- 用户暂停／取消后停止当前及后续审核，保存中断记录，不自动重试或恢复。取消的历史批次不能因本 skill 可用而重新启动。
