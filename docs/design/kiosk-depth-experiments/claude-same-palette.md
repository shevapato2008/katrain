# Claude Design：同色系按钮触感五案

这张 1024 × 600 人机对局页属于**操作界面**。五案共用当前围棋主题的配色、布局、棋盘、透明右栏、文案、字体与功能色。`c1` 在顶栏、玩家卡和胜率卡增加同色半透明玻璃层；其余四案只改变可用按钮的触感。按住按钮会下沉，禁用按钮保持平面灰态。

| 代号 | 名称 | 触感差异 |
| --- | --- | --- |
| `c1` | 清透玻璃 | 顶栏、玩家卡和胜率卡为同色半透明玻璃层；按钮有薄亮边和 2 px 短行程。 |
| `c2` | 漆面按键 | 收紧的上沿反光、厚实深色底缘；4 px 明显按压。 |
| `c3` | 精密仪表 | 小圆角、清晰切边与硬阴影；2 px 快速机械按压。 |
| `c4` | 圆润软键 | 宽而柔和的弧面反射、散开的投影；3 px 柔和下沉。 |
| `c5` | 层叠实体 | 两级底缘显示按键厚度；5 px 最深行程。 |

五案不重绘棋盘或右栏背景，也不改绿色选中态与红色危险操作的原有语义。`c1` 的卡片保留原色相和边框功能色，图表内容保持清晰。阿拉伯数字仍由演示页的独立字体切换器控制。
