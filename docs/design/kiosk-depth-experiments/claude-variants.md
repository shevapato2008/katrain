# Claude Design：人机对局页五种立体材质提案

共同表面类型是**操作界面**：棋盘与当前落子操作永远比材质效果更重要。五款都复用同一张 1024 × 600 人机对局页、56 px 顶栏、516 px 棋盘区、460 px 右栏、真实文案与图标。没有增加功能或虚构数据；只改变材质、光线、边缘和阴影。棋盘交叉点、棋子位置和曲线不做模糊。

| 代号 | 名称 | 设计意图 | 与另外四款的真实差异 |
| --- | --- | --- | --- |
| `c1` | **青岚玻璃** | 克制的液态玻璃感：暗绿环境光穿过半透明顶栏、操作卡和按钮，玻璃边缘有细亮线。 | 唯一使用 `backdrop-filter` 的方案；玻璃仅应用于导航与控制层，木棋盘及图表曲线保持锐利。活动方卡片以柔和的内层绿光抬起。 |
| `c2` | **碧玉漆器** | 从东方漆盒与玉器取材：浓绿釉面、浅金绿切边、较深的内凹图表。 | 颜色最饱和，高光集中在上缘；按钮下沿有厚度，棋盘像嵌入深色盒体。 |
| `c3` | **石墨仪表** | 金属仪表与专业棋具组合：细微拉丝、铣削边缘、紧凑倒角。 | 最规整、最硬朗；小圆角与金属线条强调每一个物理操作键，与柔软玻璃明显不同。 |
| `c4` | **青瓷白釉** | 明亮的暖白陶瓷控制台；深绿文字与轻绿当前手。 | 唯一明亮、光洁且柔和圆角的方案，反射是釉面的整体漫反射，卡片投出真实桌面阴影。 |
| `c5` | **和纸叠层** | 纸片叠放成可触控控制台：亚光纤维、错层投影、墨绿文字。 | 不使用亮面高光；纸张的偏移边缘和方角形成明显厚度，质地比陶瓷更干、更温和。 |

## 取舍边界

- 使用品牌绿与原有木棋盘；不把苹果系统或其他品牌的独有控件、图形直接搬来。
- 所有方案沿用霞鹜楷体，阿拉伯数字字族由演示页的独立数字字体切换器控制。
- 按钮至少 44 px，红色危险动作单独强调。阴影、透亮边缘均不得降低关键信息对比度。
- 本文件只供应 `#kiosk[data-theme="c1".."c5"]` 的 CSS 覆盖规则；演示页 DOM、交互与其他方案由主设计文件提供。

## 简短自检

五款没有功能卡片式首页、泛蓝紫渐变、装饰性左条、无意义大数字或凭空新增图标。`c1` 的玻璃层有真实的明暗背景和卡片高度关系；其余四款通过实色材质、边缘与投影体现深度。重点检查亮色 `c4/c5` 的曲线与次级文字对比，以及 1024 × 600 下按钮的完整呈现。
