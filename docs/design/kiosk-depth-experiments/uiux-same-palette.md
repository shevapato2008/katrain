# 同色系按钮触感方案 · UI/UX Pro Max

五款只在现有围棋配色上调整按钮材质与按压反馈。棋盘、根背景、顶栏、透明右栏、卡片与按钮功能色、文字、尺寸、位置及文案均由原演示页保留。

| 代号 | 名称 | 常态材质 | 按下反馈 |
| --- | --- | --- | --- |
| `u1` | 微雾玻璃 | 深绿底色上叠一层低透明高光和 8px 局部模糊 | 下沉 2px，高光收起，出现内凹阴影 |
| `u2` | 温润釉面 | 较宽的顶部反光和柔和圆润的表面 | 下沉 3px，外部底影变成内影 |
| `u3` | 精密键帽 | 清晰的 4px 底沿和短而硬的阴影 | 下沉 4px，模拟完整键程 |
| `u4` | 柔软按键 | 扩散的反光与宽影，保持低对比 | 下沉 3px，表面转为内凹 |
| `u5` | 悬浮薄片 | 细亮边缘与较深的分离阴影 | 下沉 3px，薄片贴近底面 |

所有方案均覆盖 `:active` 与 `.is-pressing`，禁用按钮无悬浮影或按压反馈。聚焦轮廓沿用主页面现有设置，减少动态效果时关闭过渡。
