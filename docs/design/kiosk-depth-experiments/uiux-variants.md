# UI/UX Pro Max：同一人机对局页的五种立体材质

五款共用 1024 × 600 人机对局页、56 px 顶栏、516 px 棋盘区与 460 px 右栏。页面内容、功能名称、棋盘网格、卡片和操作按钮的位置完全相同；差别只在材质、光照、边缘与触感。CSS 由 `uiux-variants.css` 提供，以 `#kiosk[data-theme="u1"…"u5"]` 切换。中文沿用霞鹜楷体，数字字体由演示页统一切换。

## U1 清透玻璃

薄青色环境光从左下与右上穿过深色背景。顶栏和右栏用半透明冷色玻璃，卡片以双层微光边缘和轻微模糊形成前后距离，当前棋手卡片有克制的青绿反射。保留暖色木棋盘，形成冷玻璃与真实棋具的材质对比。它是五款中最接近现代苹果式玻璃界面的一款；文本区保持较高玻璃不透明度，避免木纹透过文字。

## U2 焦墨漆器

以黑漆、深墨绿和黄铜边线回应围棋棋具。按钮的亮顶部与暗底缘构成上浮形态；棋盘木框有亮漆描边与内收阴影。没有大范围霓虹和模糊，偏沉稳、精致的传统器物。当前棋手用柔和金线和墨绿底区分，危险操作仍保持明确红色语义。

## U3 剧场聚光

背景压到近黑紫色，聚光落在棋盘上，右栏像舞台侧翼。棋盘更明亮，木框产生柔和金色反光；右栏卡片保持暗紫灰，当前棋手卡片用绿色小范围辉光提醒轮次。胜率卡片左边有一道灯条，让视觉顺序从棋盘过渡到数据，再到操作。光源集中在内容，避免整个屏幕一起发亮。

## U4 精密仪器

棋盘框像磨砂钛色机械面板，右栏像嵌入式显示屏。卡片边角更方正，控制键带金属高光和底部受压阴影，图表槽向内凹。蓝灰基底配少量薄荷色指示光，适合强调设备的清晰、可靠和工程感。棋盘木面仍保留，没有将围棋本体改成电子棋盘。

## U5 榫卯木作

把顶部和棋盘框作为一组深胡桃木柜体，右栏使用低饱和亚麻绿内衬。棋盘木框加入轻微纵向木材变化；卡片如浅浮的木匣，按钮如镶在柜体中的铜边实体键。整体温暖，适合家庭和儿童使用场景，同时用浅色文本和清楚的按钮轮廓保持辨识度。

## 检索依据和共同约束

先运行 `ui-ux-pro-max --design-system`，检索了沉浸式暗色交互界面；再检索 `style` 的玻璃拟态、拟物、柔性凸起与深色电影感，以及 `ux` 的暗色对比和触控目标。采用的是材质组织方式，不采用推荐的 Inter 字体或重排页面：本项目已规定霞鹜楷体和固定棋盘/右栏几何。五款都保留 SVG 图标、至少 44 px 的按钮触控区、可见键盘焦点、按压反馈与降低动态效果。玻璃款的模糊只用于有背景隔离的右栏和卡片，保证文本区不被纹理穿透；图表仍是二维曲线并保留文字数值。

这些方案是独立演示稿，待 1024 × 600 原尺寸截图与视觉评审后选出用于下一步讨论的候选，不会直接写入产品运行时代码。
