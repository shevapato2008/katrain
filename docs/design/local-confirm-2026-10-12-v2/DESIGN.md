# 本地对局逐手确认 v2

这是 **Operate（操作）** 页面。棋盘选点与本方大确认键是主操作；身份、双钟和回合供一眼判断。沿用当前 kiosk 的文楷 / Geist / JetBrains Mono 字体、龙藏品牌字、玉绿强调色、Phosphor 图标及真实木纹 / 棋子资产，所有资源内嵌，可离线打开。旧 Artifact 原样保留。

## 构图与文案

目标 1024×600，顶栏 56px；arena 位于 (16,70)，992×516。黑左白右，各 224×516；中央棋盘位于 (256,72)，512×512；两侧间隔 16px。

| 面板底部 | 相对屏幕 y | 尺寸 |
| --- | --- | --- |
| 坐标 / 手数切换 | 357 | 每枚 91×44，间隔 8 |
| 停一手 / 数子 / 认输 | 409 | 每枚 58×44，间隔 8 |

两侧各提供一组显示键，作用于同一棋盘，同步 `aria-pressed`。等待方仍可切换显示与认输，停一手、数子、确认不可用；确认中禁止业务动作。显示键的「开 / 关」使开关状态不依赖颜色。保留双侧方便双方触控，顶栏仍仅放说明入口与退出，避免棋盘工具挤占标题 / 主操作。

正常态只显示「轮到你落子 / 等待黑方」。预选态显示「已选 L8」「可改选位置」，确认键副文案「L8 · 确认后换方」；未选时仅确认键提示「先在棋盘选点」。删除常驻落子段落、数子门槛段落和重复的手数提示；门槛仍通过禁用数子与 title 保留。始终使用「停一手」，不使用通用 `Pass` 翻译。顶栏正确显示「第 32 手 · 19 路」。

多子错误只显示「请只保留这一手」「拿回多下的棋子，再确认。」并用棋盘橙色虚线标记及琥珀重试键纠正。确认中短显示「正在确认 / 正在识别」「双方计时已暂停」。等待方整体变暗，但身份 / 时间保留可读性。

## 交互与实现边界

- `?state=black / white / selected / confirming / multi`；`input=screen / physical`；`freeze=1` 固定预览钟；`byo=1` 使用读秒展示。
- 屏幕模式点击空点只替换当前预选；可反复改选，确认前仍是本方、盘上已确认棋子不变。确认完成才加入最后一点、清除预选、换方。
- 相机模式复用自由管线的确认窗口、双钟冻结、失败恢复本方、成功入谱与声音；Artifact 只表达状态，不实现独立识别流程。
- 双方停一手、数子、认输规则及终局保持原行为。说明入口保留播放说明；实际应用保留开局自动语音与成功音。原型声音 / 棋谱为设计目录内的示例，不进入生产代码。
- 原型终局按钮使用旧 Artifact 已有终局截图作参考，本次不设计终局。
