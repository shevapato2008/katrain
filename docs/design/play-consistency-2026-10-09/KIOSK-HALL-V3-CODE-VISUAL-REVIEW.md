# Kiosk 在线大厅 v3 代码质量与视觉审核

2026-10-10。依据 [已批准规格审核](KIOSK-HALL-V3-SPEC-REVIEW.md)、[实施计划](../../superpowers/plans/2026-10-09-kiosk-hall-star-alignment.md) 和 `index.html?surface=kiosk&view=hall`，独立检查 `feature/admin-console` 工作区相对 `9f28d43d` 的大厅 v3 与真实观战人数改动。实际阅读新增文件、实现差异、相关调用方和聚焦测试；此前已审核的 Galaxy 版式、直接邀请与只读观战作为既有上下文，不扩大到自由/升降级重排、部署或无关重构。

- **人数统计与生命周期。** `core/pvp_spectator_presence.py` 用锁保护会话内临时身份，HTTP 与存活 WebSocket 按正整数认证用户 ID 合并，排除双方棋手。重复标签页、HTTP/WS 同时观看、机器人座位和失效连接均有对应实现与测试。单调时钟 10 秒 TTL、最后已发布人数及单个可取消的到期回调配合工作：列表读取即使先清除了过期身份，到期回调仍会通知安静房间。`session.py:262`、`:280` 验证原会话仍在注册表，删除、替换、关闭路径清理成员和句柄；回调不读取引擎，也不刷新 `last_access`。
- **权限与兼容。** `api/pvp_spectator.py:56` 先认证、验证公共房间并成功读取权威状态，再登记 HTTP 观看；私有房间、匿名和读取失败路径不登记。严格盒子通过既有桥接验证当前身份并转发中央响应，桥接不可用返回 503，不生成本地人数。`server.py:4148` 后的 WS 生命周期在授权后登记并于 `finally` 移除；时钟启动失败也经过清理。旧 `sockets_count` 和事件 `count` 保留原始 socket 数，新增 `spectator_count` 贯穿列表、快照、初始/更新状态和人数事件，没有修改动作权限或外部 Golaxy 房间契约。
- **前端状态与交互。** `api.ts:1` 集中校验非负安全整数，两处会话 hook 保留旧字段并传递真实人数；大厅、Galaxy 房间与 kiosk 观战页对未知值明确显示“观战人数未返回”。`LobbyPage.tsx:66` 取消过期请求，并用请求序号和账号作用域阻止旧列表回填。当前控制器继续负责重连、匹配取消、直接邀请和自己的棋局返回。真实名单筛选、自身/忙碌禁邀、一次确认发送、标签键盘导航、具名弹窗焦点循环/恢复与 Escape 取消匹配均有聚焦行为覆盖。
- **真实视觉复核。** 逐张查看 games、players 的参考图、实际 React 实现、并排、叠加及差异图，以及定级、邀请和错误实现截图。1024×600 下大厅框为 `16/248/992/330`，首张棋局卡为 `24/304/484/90`；两列卡片、标签、58px 棋友行、28px 木色识别图标、黑白棋子及执子文字与批准构图一致。错误告警使列表缩短至 276px，内容仍在目标 viewport 内。保留现有外壳的品牌尺寸与间距；实现没有逐卡获取棋盘，也没有把设计样例写入生产数据。
- **字体已独立核实。** 除检查 [运行记录](kiosk-hall-v3-runtime-checks.json)，本审核另用隔离 Chrome 页面同时读取参考页和实际 React 页的 CDP 字形与计算样式。标题、操作名称及棋手名两侧实际均为 `LXGWWenKai-Bold`，字号分别为 17/15/12px，CSS 字重均为 600；人数中文为 `LXGWWenKai-Regular`，数字使用 Geist。没有中文字体回退或混用。差异图中文字的可见粗细差别来自参考页 `-webkit-font-smoothing: auto` 与应用既有 `antialiased`；标题 `normal` 行高与参考 `1.3` 产生约 0.55px 垂直差。两项是非阻塞渲染差异，不宣称像素完全相同。
