# Kiosk 棋手卡片一致性修复

## 原因与范围

摆谱页沿用自己的两张 76px 圆角矩形 `.pcard`；自由对弈、升降级与星阵人机已使用有圆角斜接缝的 SVG 梯形。GameControlPanel 的本地回退/终局及 OGS 在线分支同样仍渲染两张上下矩形。

本次抽取现有 SVG 路径为纯展示 `PlayerCardSurface`，让上述名片复用同一轮廓、配色和当前方高亮。摆谱保留 76px 高度及黑左白右；对局面板保留白左黑右、远端/本地计时来源、提子与回合文案。没有修改识别、纠错、手数推进或操作按钮条件。

盘点后保留的差异：大厅已是同类梯形；本地逐手确认的两侧 516px 整体操作席是另一个已批准布局；棋谱列表/详情及报告使用紧凑姓名条，不是本次对局名片；采集模式状态卡仍按其状态语义展示。Galaxy 不在范围内。

## 验证

- 修改前摆谱现有测试：19 passed。
- 修改后摆谱、GameControlPanel、时钟及人机分支四组现有测试：83 passed。两处“不限时”断言适配双方各有标签；自由对弈那条重复文本问题原来已存在。
- `build:smartbox-kiosk-2d` 通过，包括 strict Box SSO 与 Kiosk 边界检查。
- 本机真实 React/Vite，1024×600，对照自由对弈现有梯形，拍摄摆谱前后、OGS 和长中文/英文姓名。长姓名按现有设计省略，完整姓名保留在 title；执黑/执白和待摆坐标保留。文档尺寸为 1024×600，摆谱名片各 238×76，底部操作区止于 y586。
- 预览使用浏览器 API fixture，不请求生产、不创建真实棋局或付费任务；fixture 不进入产品源码。
