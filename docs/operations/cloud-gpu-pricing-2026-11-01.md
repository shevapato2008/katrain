## 3500 元预算如何使用

1. **按月重复扩容一台：目前证据不足以支持3500元整机预算。** 腾讯V100及截图阿里V100的3817均高于3500；阿里截图A10为3203.99、限1件，尚余296.01需覆盖未确认的盘网等，也未证明可重复采购；L20仍未取得数值。A10不能仅凭价格或卡名推定达到现有吞吐。
2. **允许三年预付：有条件线索。** 腾讯 GN10X 均摊 2595 元/月，距 3500 尚余 905；GN10Xp 均摊 2875，余 625。两项差额还要覆盖云盘、公网等；必须确认目标地域可购、实际组合报价、税和三年期限。此处月均不是严格按 30 天的厂商月租，未保证三年后续费同价。
3. **一年预付仍不够：** 两款腾讯 V100 仅计算资源的年均已为 4307.70 / 4772.50 元/月。
4. 本次结果只能作为当前价格证据及询价清单，不能保证库存、未来价或批量采购资格。现有 500 多元促销机和 3500 假设均不能替代正常扩容配置单。

| 候选 | 试跑价值 / 采购门槛 |

| 腾讯 `GN10X.2XLARGE40`（V100 32GB，8核40GiB） | 有公开价格且接近现有 GPU 架构，适合作为迁移对照；单月超预算，只有确认三年预付可接受且有货时才进入采购评估。GN10Xp 是额外 CPU 资源的备选，不必两款都买来测。 |

最低充分比较：固定两个模型文件及校验值、KataGo 版本 / 后端、棋盘 / 局面、线程与 batch、visits；分别测 web 单独、cron 单独、二者同卡。记录预热后 visits/s、web p50/p95 延迟、显存峰值、CPU 使用率和首次启动耗时。相比追求单卡峰值，双模型同卡时前台是否被 cron 拖慢更接近实际验收。KataGo 官方将后端和性能调优分开说明，支持用实际模型与设置评测。[KataGo 官方说明](https://github.com/lightvector/KataGo#tuning-for-performance)

兼容性只需先核实这些现实边界：

- 仓库 `Dockerfile.web` 的基础镜像是 `nvcr.io/nvidia/tensorrt:24.02-py3`；新云机要匹配现有 KataGo 二进制、宿主 NVIDIA 驱动、CUDA / TensorRT 版本和 GPU 支持范围，不能默认“更新到最新版”仍兼容 V100。腾讯有计算卡 Tesla 驱动与 CUDA 官方安装组合，可作询价后的环境核对依据。[腾讯驱动说明](https://cloud.tencent.com/document/product/560/76423)
- 换 GPU / TensorRT 版本时，不能默认复用 V100 上的 TensorRT engine 缓存；通常应在目标 GPU 上重建并预热。编译 / 调优增加冷启动时间，冷启动不能混入稳态吞吐比较。[NVIDIA engine 兼容性与构建说明](https://docs.nvidia.com/deeplearning/tensorrt/latest/inference-library/c-api-docs.html)
- 两模型权重之外还有工作区、batch 和并发显存，24GB / 48GB 只表示容量余量，是否足够与速度仍需测。CPU 的每核性能及线程配置影响 MCTS / 调度，8核、10核、28核的整机报价和性能不能只按 GPU 型号横比。[KataGo 后端及调优说明](https://github.com/lightvector/KataGo#tuning-for-performance)
