## 后续每批固定并列报告两项指标

按用户要求，每次实际更新数据库后同时报告累计数、占全库比例和本批新增：

1. **五语内容覆盖（固定宽口径）**：集合 A 为双方直接棋手 ID 和直接赛事类型 ID 的五语译名均合格的棋局；集合 B 为双方名称及非空原始赛事标题五语均严格合格的 raw 棋局。计数为 `|A ∪ B|`，不能在可能重叠时直接相加。
2. **严格审核全卡覆盖（逐原标题）**：保留现有具体赛事显示与双方名称均合格的严格口径。

两项分母固定为全库 **173,025**，不因列表隐藏和重复记录改变；不能称为全库线上 UI 已逐卡重测。宽口径是一套从现在起固定的明确规则，未声称与未保存完整公式的第 587 批历史口径完全等价。

第 601 批实际快照、后续第 602 批 owner-only 验证均未改变棋局与名称；快照的全局合格赛事选择集合为空。此时 A 要求直接 `event_id` 非空、B 要求直接 `event_id` 为空，两集合互斥。宽口径为 **84,554 + 32,748 = 117,302（67.7948%）**；严格口径为 **44,360（25.6379%）**。后续每批必须继续核对无合格赛事选择变化，或按真实集合去重，不能把本次互斥条件当成永远成立。
