# 棋谱库语言切换验收与修复（2026-10-08）

## 已部署的行为

- 云端精确命中唯一棋手时，仅按棋手身份检索其对局；保留未匹配棋手时的赛事搜索。原有中文搜索吴清源会把赛事标题中提到他、实际上由其他人下的七盘棋混入结果，现已排除。
- Galaxy 列表与 Kiosk 列表／详情按 lang 请求数据库中预存的显示字段；五种语言 cn/tw/jp/ko/en，其他六种英语回退。切换语言没有现场翻译调用。
- Kiosk 离开棋谱库进入设置，再返回时，当前浏览标签页保留已提交的搜索词和页码。存储不可用时仍可正常搜索。已加载旧页面需刷新一次取得新版。

## 用户验收

1. 打开 https://modelstella.com/galaxy/kifu，搜索「柯洁」或「吴清源」。
2. 设置中改为 English，再回棋谱库；检查棋手名、赛事、段位及结果切换，搜索棋局集合不变。
3. 用「Ke Jie」或「Go Seigen」检索应得到同一集合。
4. RK3562 刷新一次后，棋谱库搜索同一棋手，翻至第二页；设置改为 English 后返回，搜索词和页码应保留。

完整卡片仍受译名覆盖率限制，未翻译的对手或原始赛事字段可能保留原文；统计名单见 kifu-five-language-progress-2026-10-05.html。
