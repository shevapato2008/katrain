## 阻塞与最短取证路径

当前有明确的 **姓名/读音人物锚点**，也有 19x19 game ID → 本机 SGF → 旧库存储元数据的路径线索；中间缺的是能适用于每个拟批准成员的**人物归属声明**。`SO` 是本机脚本加入的来源标签，`userCode` 是同一公共账号值；精确姓名、合理出生后日期、段位和全部字段相等都没有消除同名、转录或执色错误。既有[赵治勋范围审计](kifu-name-bulk-player-identity-policy-decision-2026-10-02.md)已出现外观正常而完整棋谱执色冲突。本轮也没有同一时点的正式库 SGF 字节哈希/完整来源表和导入运行前像，不能冻结可写范围。
