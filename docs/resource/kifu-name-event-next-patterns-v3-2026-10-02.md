## 边界与建议

- 先考虑届次模式：日本龙星战跨 13 个写法、1,193 盘归到同一余文，日本棋圣战、十段战也出现多届写法。`第N期/届` 仍可能属于原赛事记录的正式标题部分，因此输出应只是 `edition_component` 与 `pending_review`，不可据此认定实体相同。
- 编号去除可能把不同比赛阶段、局次或赛制合并为同一待核核心。`回` 在某些日文赛名中是赛事届次，不能一概标成轮次；`轮` 和 `局` 也分别表达阶段和单局。实施时只抽取明确的单个 `第N轮/回/局`，保留原单位、跨度和值，并逐系列审核语义；不要连带删掉 `决赛`、`预选`、`败者组`、`第1场`、队名或赞助商。`第N场`、`N番棋`、比分、台次不在本候选语法内。
- 年度赛季前缀的日期边界清楚，但其余文仍可能因赞助商别名、赛制或赛事阶段而不同。保留原余文逐字差异；不要把 `2022-2023年度` 直接解释成举办日期或赛事届数。
- 仅匹配完整锚定的数字和单位；简体/繁体数字扩展需单独统计后再采纳。一次只抽取一个片段并记录偏移量；出现重复编号、全角标点或混排日期时留在人工队列，避免贪婪清洗。
