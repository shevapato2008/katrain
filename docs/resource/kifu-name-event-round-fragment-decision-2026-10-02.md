## 批准的精确边界

用 `fullmatch` 匹配下式，不裁切空白，不做繁简、数字或标点归一化：

```python
N = r"(?:[1-9][0-9]{0,2}|[１-９][０-９]{0,2}|[一二三四五六七八九]|十[一二三四五六七八九]?|[一二三四五六七八九]十[一二三四五六七八九]?)"
PATTERN = rf"(?P<left>.+?)第(?P<number>{N})轮(?P<tail>主将|快棋)?\Z"
```

同时满足以下条件：

1. 现有 v4 返回 `grammar=unparsed` 且 `exceptions=[]`；已解析成员不重新拆解。现有分类器拒绝的坏字段、程序标签和结果描述继续留在原队列。
2. 全文恰有一个字面 `第`，并且 `left.strip()` 非空。因此不处理多个编号、缺编号的 `轮`、编号后接其他尾文，或没有赛事余文的 `第三轮`。
3. 数字限同一套 ASCII／全角正整数 1–999，或上式汉字 1–99；零、前导零、混排数字、`百`、`廿`、`壹` 等留待后续统计。
4. 只将完整 `第N轮` 片段提为 `kind=round`，`value=N轮`；`text/start/end` 保留原始字符与偏移。`left` 和可选 `tail` 分别作为原文 `core` 片段；`主将`、`快棋` 仍属于完整余文。建议新语法名 `single_round_fragment`，所有输出保持 `pending_review`。
5. 分组键沿用 `(grammar, core)`，不跨语法合并；每条成员保留完整 `parts` 和轮次。年份、赞助商、国家、等级、队名及其他原文字词均保留。后续关联真实赛事或制作十一语模板仍须核实身份和组成部分语义。

例如，`2010金立手机杯围甲联赛第11轮主将` 仅形成待核余文 `2010金立手机杯围甲联赛主将`，与同年的 `…快棋`、不同年份及不同赞助商写法保持不同组。`友情杯第１轮` 的编号仍记作原文 `１轮`。
