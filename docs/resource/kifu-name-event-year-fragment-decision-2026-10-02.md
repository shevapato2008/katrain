### 1. `leading_year_range`

先匹配范围前缀，再检查剩余全文。分成两步可避免可选“年度／年”为了满足非空余文而回退，例如把只有 `2022-2023年度` 的输入误拆出 `core=度`。

```python
Y = r"(?:19|20)[0-9]{2}"
PREFIX = re.compile(
    rf"\A(?P<first>{Y})(?P<separator>[-~～])(?P<last>{Y})(?P<unit>年度|年)?"
)
CORE = re.compile(r"[A-Za-z\u3400-\u9fff].*\Z")
EXTRA_YEAR = re.compile(rf"(?<!\d){Y}(?!\d)")

m = PREFIX.match(raw)
# 所有条件必须满足；不使用 DOTALL。
eligible = (
    m is not None
    and int(m["last"]) == int(m["first"]) + 1
    and CORE.fullmatch(raw[m.end():]) is not None
    and EXTRA_YEAR.search(raw[m.end():]) is None
)
```

只接受 ASCII 1900–2099、`-`／`~`／`～`、严格连续的递增年份。余文须立即以 ASCII 字母或上述汉字区间字符开始；空白、数字或标点边界及包含另一个完整年份的余文留待后续。保留 `赛季`、届次、轮次、场次、阶段、队名及顺序于 `core`。

输出两个连续片段：`year_range` 为 `[0, m.end())`，`core` 为其后全文。`year_range.value = first + separator + last`，原分隔符不变；`text` 还保留紧随范围的“年度／年”。不拆成两个独立 `year`，不替换为开始年或结束年，不宣称实际举办日期。新语法内按完整 `core` 形成待核组。
