## 与现有模板的关系

[解析器](../../katrain/web/kifu/name_parse.py)只将精确 `段位赛` / `段位賽` / `个人赛` / `個人賽` 标为 `generic_event_description`；本次两项仍为 `unclassified_pending`。已有标签可解析不等于对应游戏已完成来源审核：既有审计还报告 `段位赛` 901 盘中 891 盘、`个人赛` 638 盘中 26 盘第二 GN 不同。因此它们不能作为这次全局批准的先例。

本次 **en/cn/tw/jp/ko/de/es/fr/ru/tr/ua 十一种语言均无新增模板批准**。以后若有逐盘证据确认只表达类别，可另审“团体比赛”与“段位晋升比赛”两个独立概念；`升段赛` 的晋升含义不能直接复用宽泛 `rank_event`。还须同步审查模板分派：[候选验证器](../../katrain/web/kifu/name_candidates.py)目前把非段位标签的 `generic` 一律派到 `individual_event`，仅扩充解析器集合会错误显示为个人赛。繁体写法、带国家/年份/轮次的变体也不随本裁决自动扩展。

完成分类所需的最小下一步是固定这 449 盘成员，读取全部根 EV/GN/GC，并按上述例外建立有依据的赛事选择及身份子集；只有被证实仅表达比赛类别的成员才进入十一语通用措辞审核。此备忘录只新增文档，未修改代码、源棋谱、数据库或提交 Git commit。
