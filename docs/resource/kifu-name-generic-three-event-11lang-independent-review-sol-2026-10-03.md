## 审核尺度与共同边界

- cn/tw/jp/ko/en：检查语义、自然度、组织名称与可追溯的术语依据；把原文、正字转换和编辑翻译分清。
- de/es/fr/ru/tr/ua：接受有可靠含义和组合规则的描述性编辑翻译，不要求在当地已存在一个同名官方赛事。
- `段位赛` 只保留“与围棋段位有关的赛事”；不把它推断为全国段位赛，也不擅自承诺特定升段制度、分组办法或参赛资格。
- `个人赛` 只保留个人赛制；不补上全国、国家、年份或锦标赛身份。
- `Hoensha game` 是方円社历史棋谱的来源/组织语境；不是“方円社杯”、全国赛事或一届月例赛。档案措辞指 CWI 收录的该组织相关史料，不声称存在一个经过认证、由该组织现今管理的独立档案机构。
