# Gosei core: independent finite source review

The [pending Gosei memo](kifu-name-gosei-core-five-source-hold-2026-10-03.md) isolated 624 albums under 44 exact raw `Gosei` variants. I independently matched the frozen inventory and event-group hashes, then read the raw SGF for every selected album: 528 files from the read-only `home-ubuntu` 19x19 source tree and 96 original [CWI SGFs](https://homepages.cwi.nl/~aeb/go/games/games/Gosei/). Each SGF root agrees with the frozen album's event string, date, black/white names, and recorded round where present. **622 albums PASS for this exact Japanese Gosei series-core source correspondence; two remain HOLD.** PASS does not approve an event entity/FK, a complete edition label, a stage label, or a game-date repair.

**Two retained HOLDs.** Album **64235** (`24thGosei`, source `41349078.sgf`) has `DT[1900-01-01]` in the SGF itself, so neither a real game date nor a repaired edition year is supported. Album **72700** (`Gosei,23rd`, source `41359497.sgf`) has conflicting root names: `GN[Gosei,23rd]` and `GN[第53期日本本因坊战预选]`; its `GC` also says Honinbo preliminary. The matching inventory `event` only repeats the first source name. Both rows remain excluded from any core PASS scope.

**Previously uncertain paths and alias.** The five games in `CWI_1950_1978/Cho_Chikun/` have exact `3rd Gosei` or `4th Gosei` SGF event roots; [CWI's Cho Chikun Gosei tournament index](https://homepages.cwi.nl/~aeb/go/games/games/Cho_Chikun/tournaments/Gosei.html) separately lists all five by exact date, edition, preliminary round, opponent, and result. Their directory difference is resolved for series-core correspondence. Album **54931** has a second root name `日本第3届小棋圣战决赛第三局`. [CWI's third Gosei record](https://homepages.cwi.nl/~aeb/go/games/games/Gosei/03/) lists the 1978-08-17 Otake–Kato final game three with the same winner and 226 moves; the original CWI title-game SGF has the same 226 colored moves as the 19x19 file. This supports the `小棋圣战` alias for this game only.
