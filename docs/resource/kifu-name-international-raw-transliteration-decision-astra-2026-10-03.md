## 新 format 4 的必要检查

复用现有独立 `content`／`approval`、规则和有限批次结构，不新增数据库表或通用身份图谱。这里的 **`anchor_format: 4` 仍装在 `bundle_format: 2` 中**；现有 `bundle_format: 4` 是赛事专用，不能混用。

1. **精确 raw 与真实源语分开记录。** 限 `entity_kind: player`、`owner.kind: raw_player`，必须有 exact `raw_value`、已签 `raw_display_scope_sha256`、原文语言依据、读法适用理由和已知拼法例外处置。`source_lang` 只准现有 `zh-Hans/zh-Hant/ja/ko`，按姓名采用的语言确定，不能按国籍或导入目录猜测。`original_name` 是源语页面实际姓名；当它与 raw 不同，另存已审的**精确 raw→源语字符串对应**。可复用本范围已 PASS 的字形对应；否则需要真实正文中的对应资料，例如同 ID 的汉字页面。不能直接把 `一力辽` 伪填成日文页面实际原文，也不能用一个全局简繁／汉字→韩文转换器代替这项证据。
2. **两份真实人物页证明来源内对应。** 最小实现只支持已核实的 GoRatings：源语姓名页和英文姓名页的 publisher、人物键命名空间、URL 语言路径和人物 ID 相符；两个页面的完整、合法 `YYYY-MM-DD` 生日相同，姓名与生日均出现在各自同一人物记录的实际正文位置。需要第三页承接 raw 写法时，它也绑定同 ID／生日。保存 HTTPS URL、捕获时间、HTTP 200、原始字节 hash、正文路径／编码、真实姓名 span 与记录定位；不能把自填摘要当原文。相同 ID 只在同一出版方命名空间内比较。首版无需通用站点注册器，其他站点另按实际需要添加。
3. **如实记录语言与对应方法。** 新 `source_link` 使用明确的同出版方本地化人物页方法，保留 `unresolved_conflicts: []` 和审核依据，不伪造官方名册、官方唯一匹配数或双出版方结论。英文来源保持 `observed_lang: en`；网页只标 `zh` 时保留观测值，脚本判断另附正文依据，不批量改成 `zh-Hant`。已知生日／姓名／资料错配未解决时 HOLD；生日仅用于来源记录对应，不因此给所有 raw 棋谱附加出生日期或年龄判断。
4. **独立批准 raw 读法适用性。** 来源精确姓名、ID 和生日不能自行完成这一步。允许对有限语料一次审核其命名语言、读法及全部相关异常，无须先证明每盘同属一个人，也不要求穷尽全球同名者。十名通常普通话读法可以复用现有 raw 适用性结论再绑定音节；日／韩读法则需新增能覆盖拟用范围的语言／读法依据，例如可核验的来源命名约定或原始名字段映射。单有 `19x19` 目录、日期段位大致连续和某位职业棋手同名不够。有同名异读、语言不同或个人特选拼法时，排除不能共用读法的槽位；不能用“六语允许合理转写”掩盖选读无依据。
5. **读音、词界和规则都必须可重算。** 沿用已审音节、规范化版本和姓名词界检查。发布的英语拼法不自动等于拼音／Hepburn／RR；特别是韩国姓名的惯用罗马字，不能换个 `reading_system` 标签便套 RR 表。与现有系统不相容的项目先 HOLD；若确需支持，须另有基于实际 Hangul／假名等的有限、已审对应及相应明确规则，不能静默增删字母。源语是日／韩时，俄／乌分别使用已审的日／韩转写规则，不能复用中文音节表。现有渲染仅拼接 token，涉及上下文变化的组合应作为明确的有限规则输入处理；不把逐 token 拼接本身当作语言正确的证明。
6. **保留完整独立签署链。** 审核者与生产者分离，批准绑定 exact 内容 hash、来源、raw 对应、范围、音节和例外，时间不早于捕获／生产。六语候选保留 `transliterated` 与规则版本，不冒称六语惯用名，也无需为该路径补做“惯用名不存在”的负面检索。Latin 四语可用已审来源罗马字显示规则，但须按源语重新绑定规则和批次；现有 `copy_roman_words_v1` 会重做首字母大小写，土语还会把词首 `i` 变成 `İ`，不能未经逐值核对就宣称逐字保留发布拼法。

这六项足以替代 raw 显示对官方人物编号的依赖，不要求增加一层密码学签名或身份抽样制度。普通日期／段位缺陷若不影响本次文字判断，不自动使 PASS 失效；若审核依赖这些字段，相关缺陷必须明确处置。

## 防止把文字决定变成同名合并

所有候选、主五语研究记录、六语锚点／成员绑定同一个已审 raw 范围。继续使用现有 `name_raw_player_scope.py` 的精确 album、色方、原文、NULL FK 和完整上下文检查；当前库前像与冻结材料有差异时重绑实际范围，不修改原 SGF、姓名、段位或日期来制造匹配。审核中的 `24170/black` 日期应使用库存真实 NULL，不能把分流文件空串写回库。

显示、严格覆盖统计和译名搜索使用相同资格判定。范围外、后来导入的同字符串、上下文漂移、已有或后来新增人物 FK 的槽位均不得自动继承。无人物创建、别名创建、跨 raw 归并、职业生涯归属或近似搜索扩展。输出碰撞保持现有拒绝自动展开规则；同显示字符串从不证明同人。

当前 73 PASS 格可用既有 raw 候选路径落实，无需等待 format 4：普通 `readable_unlinked` raw 行没有强制全十一语同时导入的代码门槛，身份关联门槛与最终全库发布门槛另行生效。已审矩阵可复用以减少重复查源，但矩阵本身不是正式 raw anchor／candidate／batch 签署；需要为实际工件作独立绑定批准。

原有 **22 格／20,392 个主五语语言×槽 HOLD 原样保留**。其中九组日／韩相关原串共 8,408 槽，en/ko 对其个人读法的 HOLD 不能由新增 format 4 代签解除。`江维杰→江維傑`、`元晟ジン`、`范廷ギョク` 等既有例外也不因六语通过而转为主五语 PASS。所有 17,241 槽的人物 FK 批准增量仍是 **0**。
