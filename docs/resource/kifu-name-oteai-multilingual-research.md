# Oteai / 大手合：十一语言名称来源调查

调查日期：2026-10-02。此文件记录来源证据和缺口，不等同于名称获批，也不授权写入名称表。

## 身份锚点与组成部分

- 日本棋院官方[沿革](https://www.nihonkiin.or.jp/profile/enkaku/)将其记作「日本棋院大手合・東西対抗」，记载 1927 年开始，1929 年废东、西制并开始春秋定期手合；官方[常见问题](https://www.nihonkiin.or.jp/profile/faq/)称 2003 年 4 月废止大手合并变更升段制度。日本棋院官方[围棋历史](https://www.nihonkiin.or.jp/teach/history/history03.html)也按年提及 1933 年大手合。
- CWI 围棋档案的[总览](https://homepages.cwi.nl/~aeb/go/games/games/Oteai/)称 Oteai 是日本棋院与关西棋院用于决定职业棋士段位的赛事，时期分别为 1927–2003、1927–2004；[1934 档案](https://homepages.cwi.nl/~aeb/go/games/games/Oteai/1934/index.html)按 Spring / Autumn 和甲、乙组编排棋谱、棋手、日期及 SGF。该档案注明原记日期 `1934-11-31` 不存在，应保留为来源异常，不能解释成真实赛日。
- 因此 Oteai / 大手合是赛事身份；年份、春/秋季、组别、轮次和对局日期是该赛事的分届或对局组成信息，不是不同赛事身份。`JapanPromotionTournament,1934,Fall` 与该身份结构相符，但单靠模式相似仍不足以自动关联每一条原始赛事值。

## 覆盖结论

- 直接发现目标语言专名证据：en、cn、tw、jp、de、es、fr、ru、tr（共 9 种）。`en Oteai`、`jp 大手合`、`cn 大手合`、`tw 大手合`、`fr Oteai`、`tr Oteai` 的来源类型和强度各异，不能统一标为主办方一手名称。
- 当前缺少可采纳的目标语专名证据：ko、ua。检索只足以记录“本轮未找到”，不构成绝对不存在的结论；在完成更有针对性的本地围棋史料/出版物检索及语言审核之前应保持待审。
- 所有翻译或转写均只标识同一赛事身份。显示如“1934 秋季大手合”或 “Oteai · Autumn 1934”时，年份和季节是届次组成，不应创建独立赛事身份；组别、轮次和具体对局日期也应分别保存。
