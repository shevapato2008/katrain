## 身份与历史结构

- [日本棋院沿革](https://www.nihonkiin.or.jp/profile/enkaku/)记载 1927 年开始「日本棋院大手合・東西対抗」，1929 年转为春秋定期手合，2003 年废止大手合并改用新升段制度。
- [CWI 1934 年档案](https://homepages.cwi.nl/~aeb/go/games/games/Oteai/1934/index.html)明确将该年 Oteai 分为 Spring、Autumn 两场及甲、乙两组，并列出棋手、日期与 SGF。它还标出史料中的 `1934-11-31` 是不存在的日期；该异常不得当作真实赛日。
- `JapanPromotionTournament,1934,Spring|Fall` 与上述档案在词义和部分对局上相符，但每个原始写法与棋局的归属仍需逐批核对。不能仅因字符串或 CWI 路径相似就自动合并赛事 ID。
