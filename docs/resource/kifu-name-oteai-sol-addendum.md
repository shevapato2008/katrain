# 大手合名称补查：韩语与乌克兰语（2026-10-02）

本记录补充[十一语言调查](kifu-name-oteai-multilingual-research.md)；只登记可读正文与证据边界，不批准名称入库。

## 韩语：找到可核对的专业围棋用例

- 韩国围棋网站 Tygem 的韩语人物长文[《실록 '100세 棋聖' 오청원》](https://m.tygem.com/news/news_view.html?seq=18833)（署名 진재호，2014-06-17）正文写“일본에서는 승단시합을 대수합(大手合)이라 부른다”，即明确把 `대수합` 与日本的 `大手合` 对应。该文随后把吴清源参加的 1930 年春季、秋季，1931 年春季、秋季及 1932 年春季、秋季升段赛逐年列出成绩；春秋是同一历史升段赛事的场次信息。文中另述 1932 年《时事新报》主办的连胜赛，属于**另一赛事**，不能并入大手合。
- [《釜山日报》2002 年围棋专栏](https://mobile.busan.com/view/busan/view.php?code=20020718000447)也在韩语正文中写“대수합(大手合)”，并说明旧日本职业升段赛、吴清源等棋士与棋谱。它与 Tygem 文同署 진재호，不能当作彼此独立的两位作者证据；两处出版物用名一致。韩语[周刊韩国的围棋专栏](https://weekly.hankooki.com/news/articleView.html?idxno=658811)也出现相同汉字对照，但内容可能同源，暂不累加独立证据权重。
- 先前候选 `오테아이` 在[韩语社区人物页面](https://namu.wiki/w/%EC%9A%B0%EC%B9%AD%EC%9C%84%EC%95%88)正文出现为“그해 가을 오테아이(大手合, 승단 대회)”，指向 1933 年秋季，但属社区编辑来源。目前专业围棋正文强证据支持的是 `대수합`；`오테아이` 可保留为待审异写，不能据此定为首选。上列史事与年份仍以[日本棋院沿革](https://www.nihonkiin.or.jp/profile/enkaku/)及[CWI 1934 春秋棋谱档案](https://homepages.cwi.nl/~aeb/go/games/games/Oteai/1934/index.html)核对赛事身份，未逐局核验 Tygem 所述战绩。

## 乌克兰语：仍未找到合格名称用例

- 本轮检索了 `Отеаї`、`Отеай`、`Отэай`、`Oteai` 与乌克兰语 `го`、`Японії`，并限查 `uk.wikipedia.org` 及乌克兰围棋联合会 `ufgo.org`。未发现可读的乌克兰语专业围棋或乌克兰语维基正文，把这些写法明确对应日本历史 `大手合`。
- [乌克兰围棋联合会论坛的“Коми”帖子](https://forum.ufgo.org/viewtopic.php?t=824)虽在 `ufgo.org` 域名下提到 `Oteai`、`Отеаи`、`Отэаи` 和日本棋局，但相关正文实际是**俄语**，不可用作乌克兰语名称证据。带 `?tl=uk` 的 Reddit 页面属界面自动翻译入口，亦不能证明乌克兰语本地惯用名。
- 结论仅为“本轮未找到可采纳来源”，并非断言该名称不存在；乌克兰语 `ua` 继续待审，不从俄语拼法猜写。任何未来的年份、春秋场次显示仍应作为大手合之下的场次信息，不另建赛事身份。
