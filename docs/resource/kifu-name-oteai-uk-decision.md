# 大手合：韩语主名与乌克兰语未命中范围裁决

日期：2026-10-02。独立裁决模型：`gpt-6-astra`，推理档位 `max`。本裁决不批准数据库写入。

- 韩语主名采用 `대수합`。[Tygem 专业正文](https://m.tygem.com/news/news_view.html?seq=18833)明确将 `대수합(大手合)` 解释为日本职业升段比赛；与[日本棋院沿革](https://www.nihonkiin.or.jp/profile/enkaku/)所记赛事身份一致。社区资料中的 `오테아이` 保留为待审异写，不作为主名。同作者的转载不累计为独立证据。
- 乌克兰语在已列公开资料范围内可批准“未发现通行名”的**逐赛事、逐语言**结论。范围及实际语言见[定向检索记录](kifu-name-oteai-uk-scope.md)：UFGO 第一期主要为乌克兰语，第二、三期正文为俄语；[UFGO 站内 Oteai 搜索](https://ufgo.org/?s=Oteai)返回无结果；[Wikidata Q4335071 精确 `uk` 查询](https://www.wikidata.org/w/api.php?action=wbgetentities&ids=Q4335071&props=labels%7Caliases%7Csitelinks&languages=uk&format=json)无标签、别名及 `ukwiki` 链接。[论坛已知线索](https://forum.ufgo.org/viewtopic.php?t=824)及[第二页](https://forum.ufgo.org/viewtopic.php?t=824&start=10)为俄语讨论/英语引文，须记作被排除线索。未索引论坛内容与线下出版物仍属于明示范围限制。
- 不开启整个乌克兰语的全局负面检索许可。每个 `owner × lang × scope` 需登记完整检查、正文哈希、分页/实际语种、排除线索、来源限制及独立审核签名；证据变化即失效。实施细节见[开发计划 Task 6a](../superpowers/plans/2026-10-02-kifu-full-name-localization.md)。
- 源语读音 `おおてあい` 可由[小学馆辞典资料](https://kotobank.jp/word/%E5%A4%A7%E6%89%8B%E5%90%88-39406)核实，赛事身份由日本棋院核实。**具体乌克兰语显示名尚未批准**：[2024 年研究](https://www.vestnik-philology.mgu.od.ua/archive/v66/12.pdf)讨论长音省略与重复两种转写，[2023 年研究](https://doi.org/10.32782/2710-4656/2023.5/32)区分词基内 `/ai/→ай` 与词素边界 `/a.i/→аї`。需按该词构词结构定规则并由独立高级审核者签署。
