## Research limits

- This pilot establishes observed source spellings and person matches only; it does not settle product-specific display-name policy or select between an endonym and an established exonym.
- For Korean, available Korean reporting presents both 우칭위안 and 고세이겐; the preferred UI form needs separate product policy.
- Turkish and Ukrainian remain unresearched to the required source standard. They need substantive native-language sources before a name can be proposed.
