# 吴清源乌克兰语主显示名裁决

**裁决代理：** `/root/wu_ua_astra_final`，实际模型 `gpt-6-astra`，`max` 推理；2026-10-01 19:48 UTC。此处记录编辑裁决，不代表数据库候选已通过工件审核或部署。

现有棋手 ID 1 的乌克兰语主显示名采用 **`Ґо Сейґен`**，类型为 `conventional`。[乌克兰语维基百科固定版本](https://uk.wikipedia.org/w/index.php?title=%D2%90%D0%BE_%D0%A1%D0%B5%D0%B9%D2%91%D0%B5%D0%BD&oldid=44688592)在标题、导言和正文使用此形；[日本棋院棋士资料](https://www.nihonkiin.or.jp/player/htm/ki001001.htm)独立核对原名、日语读音与职业身份。固定百科版本的生卒、引退时间有争议，不用于身份匹配。

[乌克兰围棋论坛帖子 p86404](https://forum.ufgo.org/viewtopic.php?p=86404#p86404)的乌克兰语正文使用 **`Го Сейген`**；发帖者页面显示乌克兰围棋协会主席身份，但这是一篇个人发言，未发现协会统一命名标准。[Mozgus 围棋文章](https://mozgus.ua/tsikavi-fakty-pro-hru-ho/)也使用这一拼法。因此它是有出处的**搜索别名**，不是错误拼写；其出处和与主显示名的取舍应随审核工件保存。百科正文的 `У Цін'юань` 可作检索别名，Mozgus 的 `Ву Ціньюань` 仅在注明较弱来源时用于检索。不得把 `Ґо Сейген` 或 `Го Сейґен` 两种混合形式伪称为有出处的别名。

裁决没有创建或批准正式候选。仍需取得固定版本原文及哈希、记录相互冲突的用法和排除主显示理由，并由独立代理审核完整候选、名称行前像与关联范围，之后才能批次入库。
