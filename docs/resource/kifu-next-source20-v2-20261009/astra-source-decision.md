## 最小修正

- **3820、5473、6547：** JSON 已附留存 Daum 完整姓名配对及其原始正文路径/哈希。绑定时与 TVBaduk POST 证据一起带入。韩文名称的公开发表依据是 TVBaduk；Daum 只补足完整中文身份桥接。保留 `乔诗`、`王伯`、`황良玉` 的真实不完整原文，不补写成官方完整汉字。完整韩文、部分汉字、既有罗马字及 Daum 全名配对一致，当前材料没有实际身份冲突，足以支持本次来源绑定。
- **6635、4568：** 保留 `generated_normative_transliteration`，完整假名与逐音节 NIKL 映射已写入 JSON。保存的搜索响应没有记录精确查询字符串，不能称可复现或穷尽的负面检索闭环；用户已允许规范转写，因此无需补做全网不存在证明。
- **3844：** 采用直接发表的 `亞歷山大·迪那斯塔因`；`迪納` 记录为异体。同页异体在两个可见行出现，修正原说明的 “once”。来源是 `zh-hant` 繁体页面，不声称该拼法独占台湾惯用名。
- **5790：** 原说明“完整汉字与 JP/TW 一致”不准确：来源为 `範希鈺`，现有名称为 `范希鈺`。记录姓氏字形差异即可；给定名、完整读音及棋手语境相符，不改现有中文。
- **引用路径：** 3771、6642、6635、4568 的 `sources/*.body` 应相对于旧来源包解析，JSON 已给出完整 repo 相对路径。保留 TVBaduk 的 POST 参数；Cyberoro 同码 GET 仅是同底层档案的可访问链接。
