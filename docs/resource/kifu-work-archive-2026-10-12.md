Docker 构建单独排除 `docs/resource/`、`.firecrawl/` 和 `tmp/` 中的研究档案，保留默认来源注册表与名称种子两个小文件。这些归档仍完整保存在 Git 中。镜像内执行历史迁移工具时，需显式挂载对应的固定档案；Web 展示使用的代码与 `katrain/web/kifu/data/` 词表仍打入镜像。

## 使用历史记录时的注意事项

1. 不同日期的候选、待审批资料和早期统计是历史记录，当前进度以最终报告为准。候选文件不表示名称已经写入数据库或取得权威核实。
2. 许多迁移工具绑定当时的文件 SHA、数据库前像、实体 ID 和表结构。数据库已继续演进，历史批次不能直接重放；拒绝漂移是这些工具的预期行为。
3. 本次更新历史测试夹具以区分旧快照和当前模型，同时保留对当前结构拒绝旧快照的检查。生产写入保护和固定研究文件没有因测试适配而放宽。
4. 归档与 Git 集成不会执行数据库迁移。原始 SGF、来源关联和译名证据用于追溯；入库状态应以实际 apply / verify 回执为准。
5. 凭据检查覆盖本次新增文件和压缩传输包。最终清洗备份的用户分析任务、分析着法等依赖记录均为空；保留的是棋谱数据及其来源关联。

清单记录文件内容 SHA-256；与历史工具绑定的路径和内容均保留。清单自身与本说明不参与自引用校验。
