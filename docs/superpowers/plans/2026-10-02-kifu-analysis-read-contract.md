# Professional kifu analysis read contract (visual preview)

The 1440×900 Galaxy report (`/galaxy/kifu/{album_id}/report`) and 1024×600 kiosk report (`/kiosk/kifu/{album_id}`) previews use `GET /api/v1/kifu/albums/{album_id}/analysis`. The Galaxy kifu library action says “查看分析报告”; the kiosk kifu list opens its report directly. The report pages reuse the personal deep report's board, AI recommendations, winrate/lead trend, seven-grade evaluation, display controls and move navigation. The separate kifu replay remains a secondary kiosk action. This is a public read of the professional archive. It does not use `user_games`, `report_tasks`, or personal billing.

The response has `album_id` (the requested row), `canonical_album_id` (the row whose analysis is shared with exact SGF duplicates), `sgf_sha256` (hash of current SGF bytes), pinned `model_sha256`, `requested_visits: 2000`, `status` (`unavailable`, `pending`, `running`, `completed`, `failed`), `total_moves`, `analyzed_moves`, `error_message`, and `moves`. Each move row uses the personal report's analysis snapshot field names for rendering, including position zero, `root_visits`, winrate, score lead, top moves, ownership, actual move/player, and grade fields. Only rows with verified `root_visits >= 2000` may appear. `completed` means every position from zero through the final move has a stored row. A changed SGF or model selection returns `unavailable` until matching analysis exists; obsolete results never appear.

The UI displays partial rows during `running` but labels progress honestly. It does not imply that `unavailable` is queued or that `failed` is complete. Both views refresh active jobs. Board mode must delegate the new read to the cloud like existing kifu reads and surface a remote failure as 503.

The temporary `analysis_preview` branches and `previewFixture.ts` were removed after the real read API was integrated. The reviewed kiosk screenshot is `katrain/web/ui/output/playwright/kiosk-report-corrected-1024x600.png` in the local worktree; the screenshot fixture never authenticated, enqueued, or persisted analysis.
