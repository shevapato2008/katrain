# Galaxy 升降级对弈设置页视觉设计

> 日期：2026-08-06
> 状态：用户已确认视觉方向
> 当前切片：`/galaxy/play/ai?mode=rated` 可开局状态

## 1. 目标与边界

本切片把现有升降级设置页迁移到已确认的 Galaxy 视觉基础，并在真实 React/MUI 运行时完成同尺寸视觉确认。
当前只闭环“进入升降级设置 → 看懂段位与本阶进度 → 确认认证对手与固定条件 → 选择执子 → 主按钮可用”。
既有 `startAiLadderGame` 处理器必须保留，但本轮视觉证据不点击主按钮、不请求开局 POST，也不进入棋盘页。

不在本切片处理：

- 自由对弈页面重构；
- 对局一级页面和其他 Galaxy 页面的风格统一；
- 棋盘内对局页；
- 跨设备占用、恢复、放弃和权威结算的生产契约；
- kiosk 1024×600 页面。

## 2. 页面层级与返回

- 一级“对局”页为 `/galaxy/play`，包含自由对弈、升降级对弈、对战大厅。
- 升降级设置页使用单行内容页头：左侧“升降级对弈”，右侧 `← 对局`。
- 返回按钮和左侧导航“对局”均导航到 `/galaxy/play`；浏览器历史返回保持默认行为。
- 页头不显示 eyebrow、面包屑、长副标题或状态 chip。
- 页头必须复用本切片新增的共享 `ContentPageHeader`，不得在页面内复制结构，也不得用大卡片包裹页头。
- 需要保留的状态说明进入旅程舞台的第一个业务区，不回填到页头。

## 3. 页面构图

桌面内容由一个连续的旅程舞台组成，不堆叠多张同权卡片：

1. 左侧主区显示当前段位、最近五局、本阶净胜分轨道及“正式对局记录”安静入口；入口指向后续记录页，
   本轮只展示视觉和可访问名称，不添加尚未确认的新路由行为。
2. 右侧挑战区显示服务器分配的认证对手、固定比赛条件、执子选择和唯一主行动。
3. 固定条件只展示真实服务端条件：19 路、中国规则、贴目 7.5、无让子，以及现有计时设置。
4. 红、绿只表达负向/正向结果；玉色承担主强调。

## 4. 状态表达

### 4.1 本轮唯一视觉验收状态：已定级、可开局

- 显示公开段位名称，不显示内部 rung 编号。
- 净胜分轨道范围固定为 −3 到 +3，并用文字同时标明降级/晋级阈值。
- 最近五局只作历史摘要，不暗示它们直接决定晋降级。

本轮固定 Fixture 为：

- `placement_state.phase="placed"`；公开段位 `5段`、内部 rung `30`（只用于断言不得显示）；
- `current_opponent` 为 `5段`、`certified`、`available`、`server`；
- `recent_ranked_results=["win","loss","win","win","loss"]`；
- `net_score=1`、`pending_settlement=false`；
- 初始执黑；计时显示 10 分钟、3 次 30 秒读秒。

### 4.2 非回归语义，不进入本轮视觉矩阵

定级、加载、错误、不可挑战和现有 `pending_settlement=true` 继续由组件单元测试覆盖，确保原有门禁、重试和
文案语义不回退；它们不生成本轮参考图或并行视觉 WIP。跨设备占用和不可变结算回执只保留在整体旅程
设计中，必须等后续公开契约冻结后再进入生产组件。

## 5. 字体、品牌与图标

- 复用现有 `GalaxyTopBar`、`GalaxySidebar`、真实 `logo-white.png` 和现有 MUI 一级导航图标。
- “智星盒”继续只使用龙藏行楷。
- 其他中文继续遵循 Galaxy 已实现的中文字体作用域；数字、英文和其他语言保持原系统字体。
- 本切片不新增字体文件、不修改 kiosk 字体边界。

## 6. 数据与 Fixture 边界

- 页面继续消费现有 `useAiLadderStatus`、`AiLadderStatus`、`startAiLadderGame` 和 `canStartAiLadderGame`。
- 生产组件不包含模拟业务数据、Fixture query 参数或私有认证集合判断。
- `katrain/web/ui/tests/fixtures/galaxy-ai-ladder-status.ts` 是仅供 Playwright 使用的确定性测试数据，拦截
  `GET /api/v1/ai-ladder/status`，不进入运行时 bundle，也不是待删除的生产 Fixture。
- 该测试数据作为视觉回归输入保留；生产代码从始至终不包含模拟业务数据，因此不存在后续删除生产
  Fixture 的债务。

## 7. 视觉验收

第一轮目标 viewport 为 1440×900。权威参考为已获用户方向认可的高保真稿，冻结输出路径为
`superpowers/tracks/galaxy-ai-ladder-journey/visual/setup/1440x900/reference.png`。必须同时产出实现截图、
并排图和叠加/差异图。用户明确确认前，不得进入本旅程的后端改造。

确认桌面主构图后，再检查 1200×800、1024×768、900×700 和 430×880：桌面双列在空间不足时按
“段位旅程 → 本局挑战”顺序纵向排列；内容区是唯一滚动所有者；不得出现横向滚动；主行动必须可滚动到达；
430×880 继续使用 Galaxy 移动壳层和固定底部导航。
