# 平台品牌标记

这里放的是**第三方的品牌资产**，不是我们的图标。

## 和 `src/kiosk-shell/icons/` 的区别（重要）

| | `kiosk-shell/icons/` | 这里 |
|---|---|---|
| 来源 | Phosphor v2（MIT），整目录抄来 | 各平台官方 |
| 真源 | `smartbox-software` 的共享包 | 各平台自己的站点/应用商店 |
| 指纹 | 由 `kiosk-shell/MANIFEST.sha256` 钉死 | **不进 MANIFEST** |
| 上色 | `currentColor`，随容器变色 | 保留原色，不染 |
| 缺了怎么办 | **抛异常**——少一个图标是 bug | **回落到地球图标**——见下 |

**不要把这里的文件加进 `MANIFEST.sha256`**，也不要把它们挪进 `icons/`。那份清单说的是
「四个前端用同一份字节的 Phosphor 图标」，这三个文件既不是 Phosphor、也不该被其它棋类共用。

## 为什么缺了是回落不是报错

平台列表是服务端 `/platforms` 下发的。服务端哪天多返回一家我们没有标记的平台是**正常事件**，
照 `Icon` 那样抛，会因为服务端多了一行就把首页打白。所以 `PLATFORM_MARKS` 查不到时回落到
`globe-hemisphere-west`，并且**保留 accent 染色** —— 那正好诚实地说「一个网上的平台，
我们没有它的标记」，而不是假装有。

### OGS 为什么用这版黑白棋子，不用官网首页那个蓝黄圆

**那两个是同一条路径、只换了填色。** 逐字比过：`d=` 完全相同，差别只在
`fill:#0057b7`/`gold`（首页那版）对 `fill:#dededd`/`#010101`（这版）。
`#0057b7` 是乌克兰国旗蓝的官方色值 —— 首页那版是把他们自己那颗**围棋子**换成国旗配色的
声援版。三条理由用这版：

1. 不往一台面向中国市场的设备里内置政治表态；
2. 声援配色很可能是临时的，对方换回去我们就成了过期的怪东西；
3. 它本来就是**一颗围棋子**，放在围棋产品里比什么都合适。

轮廓和首页那个圆一模一样，认得出。

> ⚠️ 别用 CDN 上的 `apple-touch-icon-*.png` / `android-chrome-192x192.png`：同样是这颗棋子，
> 但**不透明白底**，贴到深色 UI 上是个白方块。

### 野狐为什么用应用图标，不用官网那个圆

官网 `Public/Images/logo.png` 是「圆 + 书法字」的横向组合，整张只有 154×48，圆那部分约
46×48px —— 放到 40 CSS px 只有 1.2 倍余量，而且圆和「野」字有重叠、切不干净。
应用图标 1024×1024 到 40px 是 25 倍降采样，不存在糊的可能。

> ⚠️ 腾讯围棋（`com.tencent.TtgoForIos`）的应用图标是**完全不同的设计**（棋子+竹子），
> 不是这个火焰标，别混。

## 为什么只取标记不取字标

两个槽里品牌名都已经用**我们自己的字体**排在标记旁边了（中文霞鹜文楷、拉丁 Newsreader）。
取字标会把对方的西文字体（GOLAXY）和书法字（野狐围棋）一起搬进来，和整屏打架。
