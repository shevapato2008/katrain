# 正式采集前端 v2 视觉记录

入口：[四图](./vision-v2-fourup.html)，[操作设计](./admin-vision-capture-v2.html)。目标均为 Chromium 1440×900；无缩放，夜间未连接、夜间可采集、恢复待复核与白天样本检查。

- 构图/几何：左预览、右 360px 顺序操作、下方数据集；270px 双图同源，不做原图视觉变形。可采集主按钮在 900px 内完整可见；stale 多出必要复核/新标定出口，页面允许自然滚动。
- 层级/字体/色材：复用正式后台 CSS、楷体、B 夜间暖铜与 C 白天蓝灰主题，内容字号不回到先前过大版；边框、表单、弹窗与原有模块一致。
- 图标/资源：生产用现有 Lucide；棋盘图为浏览器临时 JPEG 响应，样本蓝框仅验证服务端叠框展示属性，不能当标注或相机算法验收。
- 文案/状态：真实元信息与 SGF 手数取代设计示例；无硬件时空图。运行图的测试说明由截图脚本临时插入，不进生产。正式导航暂不显示未集成的性能监控，设计中的第四导航仅预告。样本检查多一项“已重新摆放并核对”确认，避免只勾重拍意图就修改样本。
- 已知数据差异：测试 frame/hash 与设计说明不同，截图的临时响应不是采集产物；恢复提示真实反馈导致必要几何位移。不以差异图黑底面积宣称像素相同。
- 独立 GPT-6 Astra max 实际检查参考/实现/并排/叠加与差异：前三态 APPROVE；浅色初次截到加载态，仅补该态等待弹窗及图像解码后重新裁定 APPROVE。四态最终通过，Fan 明早仍可复核。

后续审核补充的坏样本重拍出口采用同一弹窗样式：显示服务器真实错误与 manifest 帧元信息，不伪造缺失叠框/标签；保留双确认与真实准备闸。需聚焦预览及行为测试，不重复全状态视觉链。
