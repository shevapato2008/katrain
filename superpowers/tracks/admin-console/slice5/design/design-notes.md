## 构图与视觉

主 **Monitor**、次 **Inspect**。目标 1440×900：紧凑控制栏在上，四张图像阶段首行、三份棋盘次行；七阶段整屏对照，点击可放大。公共模型和批次元数据集中一次展示，贡献帧与预算通过原生 details 查看，避免七格重复长 hash。首拍陈旧态下方说明超出首屏，按真实截图反馈仅将图像画布 132→114px、棋盘画布 166→124px，保持关键字号与放大入口，优先保证七阶段完整首屏。

直接导入真实 `AdminApp.css`；使用最终 B 石墨铜夜 / C 雾蓝日 tokens、楷体、80px 顶栏与 280px 侧栏。主标题 30px，关键阶段/按钮 17px，状态/版本 16px，说明 13–14px；不把教程旧大字号带进诊断密集视图。浅色警告使用现有 warn tokens，焦点使用 admin-focus，状态配图标和短字。

已完整使用 claude-design 与 ui-ux-pro-max。本轮 uiux 查询建议 Data-Dense Dashboard、可放大检查、键盘焦点和可恢复错误，已采纳；通用推荐的运营 landing hero、绿色 CTA 和 Fira 字体不适用于已批准的产品语言，未采纳。无需另建 design-system 或三个布局变体。

## 状态入口

`admin-vision-diagnostics.html?state=unconnected-dark&capture=true`

- `unconnected-dark`：无在线设备、假图像、假产物；七格占位，开始/激活/回滚禁用，返回流程 1 的显式出口。
- `ready-dark`：明确标记设计就绪；模型及设备核实均非真实结果，无诊断画面。开始需确认。
- `running-dark`：七格全部是 canvas 合成示意，标题和每图标记非相机实图；只能停止，切模型先停止。
- `stale-light`：整份上次示意批次保留，统一陈旧警告，七格不拼新旧；停止后核实设备/标定。公共批次行显示观察时间及“8秒未更新（示意）”；未知/就绪无虚构观察时间，不新增时间面板。

`capture=true` 隐藏 Tweaks。默认未连接。Tweaks 的“加载失败”只演示失败页：诊断已停止，当前和前一模型不变。控制按钮只切示意状态，不请求网络、不加载 torch、不接硬件。流程 1/2 链接只跳到已存在 HTML 设计稿，不伪称实际业务导航。远程下载始终 disabled / 待授权。

## 七阶段的权威边界

1. 本轮原帧与 GeometryLock 叠图，不另取新帧。
2. 生产 margin 的平均前纯 warp；不是 YOLO 输入。
3. 真实平均（最多 8 帧）＋CLAHE 输入背景，模型 NMS 后、业务去重前框。
4. 同一实际推理输入背景，业务去重＋阴影剔除框；keep / sustain 与实际赋值输入不同，不能称全部参与赋值。
5. **原始定位投影·诊断派生**：标题/副标与说明明确配对，最近点落格、越界丢弃、同格最高置信度；不是生产中間结果，不做视差/sticky/spill/掩码/历史，不回灌。
6. 本轮唯一一次真实 `detections_to_board()` 返回；纠偏、占位等仅观察已有结果。
7. 两帧 vote → deny mask → reference check 后实际发布棋盘；Mac viewer 无对局基线，参考检查与落子确认显示未参与，不新造第八盘。

这里的 canvas 只解释构图，绝不是实际算法结果。下一 Fixture 与真实接入必须按 recognition-observation-notes 的单次 InProcessAdapter 只读 observer 裁定实现，不以本稿画图模拟业务。

## 确认与失败

激活、回滚、开始均原生 dialog，提供返回/ESC；确认按钮在勾选前禁用。加载失败保留当前与上一版，诊断停；旧线程退出未核实的实际 busy 门禁留待契约冻结，不以设计停止按钮证明线程已退出。七格放大 dialog 提供关闭/ESC，键盘焦点清晰。

显示预算在共享来源面板：最新完整快照＋生成中各一份，最多三底图，长边≤960，每 JPEG≤1MiB，框每阶段≤4096，总响应≤8MiB；超限应报不可用，不静默裁剪。模型长 hash 的具体只读字段、完整帧身份与单调时间由四图确认后的实际契约冻结，本稿以显式 design 字符串占位，绝不伪造真实 SHA256。
