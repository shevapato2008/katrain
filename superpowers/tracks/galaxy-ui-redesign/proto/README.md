# galaxy 可点击原型（本轮设计冻结）

`style-unify-scope.md` 把这份原型列为本轮的**权威之四**（设计冻结）。
在 2026-08-22 之前它只存在于会话的 scratchpad（`/tmp/.../scratchpad/proto/`）里，
**没有 git**、也不会跨会话存在 —— 也就是说这份「冻结」随时可能消失，
而任何建在它上面的闸都会跟着消失。本次归档就是为了消除这一点。

## 目录里是什么

| 文件 | 是什么 |
|---|---|
| `galaxy-prototype.html` | **构建产物** —— 直接用浏览器打开的那一份，Fan 审过的就是它 |
| `build.py` | 把下面的分片拼成上面那一份 |
| `01-head.html` … `10-v2.js` | 分片源码（页头 / 图标 / 样式 / 运行时 / 外壳 / 各屏 / 事件 / 总览 / V2） |
| `check.py` | 原型自查（见下） |
| `loadbearing.js` | 原型自己的承重探针 |

当时调试用的一次性脚本（`fixes*.py`、`restore*.py`、`probe*.js`、`sweep.js`、
`dump.js` 等）和 51 张工作截图（约 28MB）**没有归档** —— 它们是过程物，
留着只会让人误以为是可用工具。

## `check.py` 检的是什么，以及它看不见什么

`check.py` 把**控件清单**（每屏应有哪些控件）与**原型渲染出来的标签**做匹配，
回答「清单里的每个控件在原型里画出来了没有」。它是标签匹配。

它看不见的是**形状**：返回键放在哪、页头是单行还是两行、有没有副标题——
这些东西在标签匹配眼里完全一样。2026-08-22 规范 §2.4 按 Fan 的裁定改写
（返回键移到左上角、上一级简称不上屏），实现跟着改了，
而原型的 `cph()` 没跟，`check.py` 全程报绿，最后是靠人工比对抓到的。

**所以 `check.py` 不是这条漏洞的补丁。** 补它的是同目录上一级的
`check_spec_sync.py`：规范小节的正文一改，所有登记在册的消费方
（实现、测试、以及这份原型的 `04-runtime.js`）就必须重新声明自己看过新版，
否则闸红。两者互不替代 —— 一个查「控件画了没有」，一个查「有没有跟上规范」。

跑法：

```bash
python3 superpowers/tracks/galaxy-ui-redesign/check_spec_sync.py
```
