## 0. 先纠三条事实 —— 都是查出来的,两条和我们的假设相反

### ① 「sample-go 的绿比我们的亮」—— **不成立,是同一个值**

`sample-go/go-kiosk.tmpl.html:22` 写着 `--accent: #58B57A`,而该文件第 10–14 行的注释直说:

> 取值逐个来自真前端 `katrain/web/ui/src/kiosk/theme.ts` 的 `kioskTheme`,**不是这儿新调的**

⇒ 稿子的青玉**就是**我们的 `#58b57a`,不用改。看着亮是**用法**不同:稿子把它用成底部导航那块**实心填充**,我们只用在细描边和文字上。**这一条别改颜色,改用法。**

### ② 真正错的是**层次数**,而 `--paper` 是我上一轮**编的**

go 稿子的表面是**三层**,而且是**越往上越亮**:

| token | 值 | 用在哪 |
|---|---|---|
| `--ink` | `#0F1416` | 页底 |
| `--panel` | `#18211F` | 面板 / 内格 |
| `--raise` | `#1D2725` | **抬起面(卡片本身)** |

我们 `go-tokens.css` 把 `--panel` 和 `--raise` 都设成了 `#18211F`(层次塌成两层),又**自己发明**了
`--paper: #121a18` 当「凹面」。**go 稿子里根本没有 `--paper`**,而且方向反了:
稿子的卡片比页底**亮**,内格比卡片**暗一档但仍亮于页底**。

⇒ 改成:卡片 `--raise`,内格 `--panel`,`--paper` 作为兼容别名指向 `--panel`(象棋模板用它)。

### ③ 稿子还有我们没有的几个 token

`--info: #5B9BD5`(「后端已有、界面还没接」,与「后端根本没有」的琥珀分开)、
盘面配方 `--gb-light #E9CB92 / --gb-dark #CAA66F / --gb-line #46331B / --gb-black #16161A / --gb-white #F3F0E7`、
`--board-ruler-ink #CBAE80`、`--oak` / `--darkwood`(来自 `board-assets.json`,**别自己造**)。

## 3. 内联 还是 浮层 —— **选内联(象棋派)**,三条理由

| | 象棋(内联) | 国象(浮层) |
|---|---|---|
| 挡局态是什么 | **这一屏的内容** | 压在屏上的**死路通知** |
| 提供的动作 | 继续等待 / 按认输结束 | 留在这里 / **去普通对弈** |
| 能不能从这台机器了结 | 能 | **不能**(文案:「请先在原盒子结束并同步该局」) |

**围棋语义上是象棋那一侧:**

1. **我们能从这台机器了结** —— 认输 / 让掉 / 立即重试,三个都是**改变状态**的动作。
   国象的浮层只有两个出口且都不改状态(留下、或走开),浮层适合**死路**;我们这儿不是死路。
2. **这一格的数会自己变** —— 后台每 15 秒复查,倒计时在本地走秒,「立即重试」按下后
   重试次数与下次时刻当场变。**一个必须跨越 15 秒刷新、内含活倒计时和会变的按钮的浮层,
   是比内联面板更差的容器**(焦点、`aria-live`、以及"弹窗开着底下变了"的老问题都要重打一遍)。
3. **底下那些设置此刻一个都用不上** —— 浮层会把它们留在视野里(国象接受这一点,因为它的用户
   本来就该走开);我们已经拍板「整栏换成挡局面板」,内联与那条决定一致。

> 判据:**浮层适合"你在这儿做不了任何事,去别处";内联适合"你要做的事就在这儿"。**

## 4. 承重(布局全变,全部重打)

判据不变,但**比较对象跟着盒子链走**(上一轮就是没跟着搬,九格一起红在假缺陷上):

- 必需信息:标题(卡①)、事实格(卡③)—— 都在**不参与滚动**的位置 ⇒ 比**视口**;
- 可滚的只有右栏 `kiosk-side__scroll`,判据仍是「`overflow-y` 是 auto/scroll 且 `scrollTop` 真能推」;
- 动作行贴底,`actionsBottom ≤ innerHeight`;
- 余量口径:**动作行顶边 − 它之前最后一个真的渲染出来的元素的底边**(量空的那一段);
- 变异量必须**大于闸的余量**,而闸的余量 ≠ 表里的余量(上一轮实测差了一倍多)。

新增一条这一轮特有的:**左栏那块盘不随状态变** —— 六态下 `kiosk-console` 的几何应当逐格相同,
写成断言(它是"骨架没被带歪"最直接的证据)。
