对弈 hub — 状态与竖屏规范

把已定稿的「对弈」界面补齐到可实现颗粒度：交互状态（默认 / 悬停 / 按压 / 聚焦 / 禁用）、异步与数据态（继续上一局 有无、等级 加载/失败/空）、动效与触控数值，以及 7″ 竖屏排布。组件、图标、盘面均与 ③ d3 定稿一致（统一等大 .opt 网格 · galaxy MUI 图标 · galaxy 木纹棋盘棋子）。字体为 Anthropic 风格替身（Newsreader + Hanken Grotesk）。

  • 棋盘台由左侧竖栏 → 顶部横卡（小盘 118px + 状态竖排），省竖向空间。
  • hub 从两分栏 → 单列堆叠：人机（自由/升降级/跨平台 单列）+ 人人（三项一行 compact .opt）。
  • Dock 不变，仍 8 项底部等分；标签字号降到 10.5px。
  • 竖屏内容超一屏时，仅**内容区**滚动，Header 与 Dock 固定。
  • 触发：`OrientationContext.isPortrait`（现有），走这套排布。

动效与触控数值

项数值说明
按压缩放scale .97（次操作/dock）· .985（主操作大卡）触控主反馈；transform-origin:center
时长 / 缓动130ms · cubic-bezier(.2,.7,.3,1)入快出稳；`prefers-reduced-motion` 时关位移，仅留色变
悬停.opt translateY(-1px) + border 提亮鼠标/笔用；触控无 hover
聚焦环0 0 0 2px 底 , 0 0 0 4px rgba(88,181,122,.75)键盘/遥控导航可见；`:focus-visible`
禁用透明度 .4 + grayscale(.5)，`pointer-events:none`如未连接的在线大厅、加载失败的主操作
触控靶Dock 格 ≈ 120×70；.opt ≥ 64 高≥ 44px 可触基线
骨架/加载skeleton 位移 1.4s；spinner 1s 线性等级加载 / 创建对局中
