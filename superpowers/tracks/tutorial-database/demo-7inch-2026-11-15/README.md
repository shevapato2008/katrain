# 7英寸教程 Demo — 2026-11-15

本机入口：[打开7英寸教程Demo](http://127.0.0.1:18950/?demo=20261115-v2#chapter=2)。双击同目录的 `start_demo.command` 可启动或重新打开。

这是独立的本地前端预览，固定逻辑画布1024×600，沿用现有Kiosk的青毡配色、霞鹜文楷字体、触控按钮和双列小节目录。可用“1:1像素”“自适应”“全屏演示”检查7英寸布局；Mac画面不代表RK3562硬件解码性能已验收。

## 可演示内容

- 前3章：入门知识、基本规则、基础技巧，54个真实OGS小节。
- 16段现有视频，约13.2分钟，映射到其中14个小节；未选编视频的小节明确标注“视频待补”，练习仍可进入。
- 视频来自已生成的教材原图讲解；每段保留书名、PDF页码。`manifest.json`给出准确媒体对象键、两种规格和字节数。
- 练习使用正式环境现有OGS公开课程数据，复用项目的`ogsExercise.ts`判定与围棋规则。落子题直接点棋盘；原题是数气选择时才显示选项。答对、答错均提供对应主题提示，可重试或重看讲解。

建议演示顺序：

1. **基本规则 → 气**：播放四口气、棋块数气两段；进入练习，先答错再重试。
2. **基本规则 → 打吃**：看只剩一口气的讲解。
3. **基本规则 → 提子**：看黑1堵气提子，再在OGS棋盘直接落子并看到提子和判定。
4. 有时间再演示**寻找解救方法**的错误与正确分支，或**基础技巧 → 征子**。

## 在线与本地备用

默认视频按需从TEST媒体服务器读取。为了模拟正式站同源播放，本地`/stream/{figure}.mp4`只转发清单中固定的公开视频URL及Range，不需要Admin登录，不写远程接口。

“本地备用”改为播放Mac上已缓存的16段盒端视频，总18.79MiB；这不是把全量教程放入盒子。30道真实练习已预取，包含“气”和“提子”的整节；其它练习首次进入时联网读取并缓存。字体使用仓库已有自托管字体，无外部字体CDN。

正式环境已经有OGS7章/248节，但新视频仍在TEST；此次没有修改正式数据库、盒子或正式服务。正式部署见同级目录的[投放设计](../demo-deployment-2026-11-15.md)。

## 维护与材料

- `prepare.py`：读取现有媒体清单及OGS公开接口，缓存既有视频、首批练习及封面，不生成音视频。
- `demo.ts` / `demo.js`：独立Demo源码及已构建脚本；只导入已有练习逻辑，不依赖完整React应用启动。
- `serve.py`：仅监听127.0.0.1的预览服务。
- `course.json`、`manifest.json`：真实课程及本轮选编快照。媒体与练习缓存不进入产品构建。
- `media-cache/`：仅既有Kiosk视频的Mac本地备用；`posters/`为从这些视频提取的封面。

重新构建JS可使用esbuild：`esbuild demo.ts --bundle --platform=browser --format=iife --target=es2020 --outfile=demo.js`。正常演示无需安装依赖或重新构建。
