# 棋子成像视差 —— 推导、实测输入与校核

日期:2026-09-21。几何源自 Fusion 文档 `ver9-camera-mount-fixed-j2`(棋智盒 ver9 摄像头杆)。
本文所有数字都是**量出来的**或从量出来的数**闭式解出来的**,没有估值。

## 1. 机理

摄像头不是正上方俯拍。识别器报的「棋子中心」在棋盘面上方 h 处,沿视线投回棋盘平面时
落在真实落子点的外侧;离镜头正下方(nadir)越远,外移越多。

## 2. 公式

设 C 为镜头投影中心在棋盘平面上的垂足(nadir),H 为镜头离棋盘面高度,
h 为棋子视觉中心离棋盘面高度,P 为真实落点,D 为识别到的位置(均为棋盘平面坐标):

```
正向   D = C + (P − C) · m        m = H / (H − h)
反向   P = C + (D − C) · k        k = (H − h) / H = 1/m
偏移   Δ = D − P = (P − C) · h/(H − h)
```

三条性质,实现时都会用到:

1. **方向**:永远从 nadir 径向朝外;大小与到 nadir 的水平距离严格成正比。
2. **与相机姿态无关**:俯角、焦距、FOV、畸变都不进公式。前提是图像已用棋盘四角 / 网格
   做过透视矫正,计算发生在棋盘平面坐标里。这是纯针孔几何结论 —— 偏移只取决于**投影中心
   的位置**和**离面高度**,与像平面怎么摆无关。
3. **仿射不变**:位似经任何仿射映射 A 共轭之后还是位似,中心变成 A(C),**系数 k 不变**:

   ```
   A(D) = A(C + m(P−C)) = M·C + t + m·M·(P−C) = A(C) + m·(A(P) − A(C))
   ```

   所以修正可以直接做在流水线自己的 (x_mm, y_mm) 或连续网格坐标 (fx, fy) 上,
   只需要把 nadir 表示成同一坐标系里的一对数。**k 不需要换算。**

### h 为什么取厚度的一半

棋子体积实测 1773.9527 mm³,而 (4/3)π·11²·3.5 = 1773.9527 —— **一模一样**。
所以棋子是 a=11、c=3.5 的扁椭球,关于中平面严格对称。对称体的投影轮廓也关于中平面的
投影对称,所以 bbox 中心 / 椭圆拟合中心对应的就是中平面,即 **h = t/2 = 3.5**。

这是个有依据的结论,不是取中值。**但它只在识别器报的是轮廓中心时成立** ——
如果报的是顶面圆心,h = t = 7.0。两者差一倍,只能靠现场标定判定(见 PRD §3 P1-2)。

## 5. 校核:线性公式 vs 精确二次曲面

线性公式把棋子当成一个点。真棋子是扁椭球,从镜头看过去的轮廓是**切锥与椭球的交线**。
用两个精确模型独立算了 361 个点(`verify_quadric.py`),报实际残差 —— 不是把公式自己的
算术再算一遍:

| 模型 | 含义 | 残差 max | 残差 mean |
|---|---|---:|---:|
| **A** | 从镜头向椭球作切锥,与棋盘平面相交得圆锥曲线,取其中心。对应**先把整幅图透视矫正、再在矫正图上跑检测** | **0.053 mm** | 0.030 mm |
| **B** | 同一切锥投到真实像平面(法向 = 光轴,俯角 62°)得椭圆,取像平面上的椭圆中心,再沿视线反投回棋盘面。对应**在原图上取 bbox 中心、再用单应把这一个点映过去** | **0.181 mm** | 0.127 mm |

两者都远小于半格 11.0 mm,也远小于偏移本身 5 mm。**线性公式可以直接用。**

数学:椭球齐次矩阵 Q,从 C 作的切锥 `K = (CᵀQC)·Q − (QC)(QC)ᵀ`,
把 K 限制到目标平面得 3×3 圆锥曲线矩阵,解其中心。

`parallax_correct.py` 的自检:361 点正向 → 反向往返误差 < 1e-9,snap 全部回到原交点。

## 6. 现场标定(推荐路径)

正向模型 `D = m·P + (1−m)·C` 对 (m, bx, by) 是**线性的**:

```
D_x = m·P_x + b_x
D_y = m·P_y + b_y        b = (1−m)·C,m 两轴共用
```

在若干已知交点各放一颗棋子、记下识别到的位置,最小二乘解出 m 与 C = b/(1−m)。
四角 + 天元五点即可(10 个方程 3 个未知数)。解出来的 m 把 h、入瞳位置、装配误差
**一次性全部吸收**,所以不需要事先知道 h 到底是 3.5 还是 7.0。

副产品 `h_implied = H·(1 − 1/m)`:拿它和 3.5 / 7.0 对一下,就知道识别器报的是哪个高度。

见 `parallax_correct.py::fit_from_samples`。

## 7. 边界

- 镜头参考点取 `lens_mm`,是**镜头前表面**,不是入瞳。入瞳若再沿光轴后退 3 mm,
  H 变 +2.65(0.79%),k 变 < 1% —— 远小于 h 本身的不确定度(3.5 vs 7.0 差一倍)。
  标定会把这一项一起吸收。
- 模型假设棋子底面贴在棋盘面上。CAD 里的网格凸起 0.1 mm 会让 k 变 0.03%,可忽略;
  实物棋盘是 UV 印刷的平面,没有这一项。
- 棋盘对位(ΔX +14 / ΔY +2 / ΔZ −2.5)在 Fusion 里还没做。未做时 nadir 在 x=0 而
  棋盘中心在 x=−14,X 方向偏移左右不对称(左最远列 227.3、右 199.3)。
- **这是几何推算,不是识别率测试。** 装机后要在相同光照 / 棋局 / 模型下比对修正前后的
  漏检与误检。
